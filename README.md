# cocoa-bean-rating-ensemble
Machine learning analysis evaluating global cocoa bean production locations and company ratings using comprehensive EDA and ensemble modelling (Bagging, Boosting, Stacking, Voting)

# Cocoa Bean Production & Company Rating Analysis

## 1. Business Problem
* **Objective:** Identify key features influencing cocoa bean ratings and accurately classify global companies based on production location and quality metrics.
* **Constraints:** Dealing with categorical geographic variables and subjective rating distributions.

## 2. Data Dictionary & EDA
* Mapping features like bean origin, company location, cocoa percentage, and rating scores.
* Univariate and bivariate analysis to discover geographic trends and top-performing bean sources.

## 3. Model Building & Ensemble Techniques
* Feature selection and scaling on numerical/categorical features.
* Implementation of Bagging, Boosting, Stacking, and Voting classifiers.
* Performance comparison using confusion matrices and cross-validation.

## 4. Business Impact
* Helps chocolate manufacturers and suppliers identify top-tier sourcing regions, optimize quality control, and make data-driven supply chain decisions.
